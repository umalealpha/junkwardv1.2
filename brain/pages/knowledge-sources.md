Three linked stores, kept in step:
1. **MACHINE-TALK.md** (this repo, append-only, one line per session, merge=union) = the cross-machine SESSION LOG / "what the other seat did". Synced across both machines by git.
2. **Omni notebook** (omni.alphadirect.co.bw/notebook, read via ~/.claude/read-notebook.sh) = the SETTLED FACTS / people / frozen figures. Server-hosted, so it is already one shared copy for both machines and the phone.
3. **This brain** (brain/ in this repo) = durable DECISIONS. Synced across machines by git, same as MACHINE-TALK.
Rule: a durable decision lands in the brain; the session log records the session; the notebook holds settled reference facts. This brain was seeded from MACHINE-TALK on 22-Aug-2026. Keep them consistent — when a decision changes, update the brain page and note it in MACHINE-TALK.
