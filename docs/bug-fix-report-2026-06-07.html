Dumelang,

Following the testing feedback, a full multi-perspective audit of omni / alpha-finance was run (chartered-accountant, auditor, ISO and software-engineering lenses), exercising the real code through the test suite, Django system checks and static analysis — not just confirming that things compile.

Headline: the system could not rebuild its database from scratch (the test suite, CI and disaster-recovery rebuild were all broken; production survived only because it was built up incrementally). That is now fixed. The full automated test suite passes 40/40, up from 17 errors with a database that would not even build.
